# Instinct codebase

Persistent source repository for the user's work pipelines: question-bank PDFs, video production, portfolio builds and research. This starter scaffold contains project notes and a task overview; runnable scripts and finished outputs will be added as each pipeline is built and checked.

- `tasks.md`: current work and possible next projects.
- `pdf-builder/`: question-bank tools and checks.
- `video-pipeline/`: video scripts, editing templates and test notes.
- `portfolio/`: website source and deployment notes.
- `research/`: source-backed briefs and reusable research data.

Keep credentials, authentication codes and private account data out of this repository. Keep this repository private. Potential tasks are ideas, not permission to send messages, spend money or start new services.
