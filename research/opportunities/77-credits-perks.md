## 2 October 2026: official-page checks

| Offer | What the source supports | Important limits |
|---|---|---|
| GitHub Student Developer Pack | Current pack of partner tools; official student-application documentation requires age 13+, enrolment in a degree/diploma-granting course (including high school/homeschool) and student verification. | Not every partner benefit shares the same age/geography terms. Do not infer P is verified or eligible. |
| Azure for Students Starter | Free selected Azure services, not the $100 balance. Official offer says 13+ in US, 16+ outside US, academic verification. | GitHub pack separately advertises an Azure 13-17 benefit. UK under-16 availability should not be assumed from the pack label against Microsoft's offer terms. |
| Azure for Students | $100 for 12 months; official FAQ requires full-time enrolment at an accredited degree-granting 2-4 year university. | School attendance alone is not enough. Usage credit, not cash; do not upgrade to paid billing without approval. |
| Zed Student | One year of Pro and $10/month AI token credits. | Accredited university, age 18+, GitHub account older than 30 days, current university email. Automatically drops to Free after one year. Not unlimited model access. |
| Figma Education | Free education tools with education verification; page covers K-12 and higher education. | Check current applicant/team eligibility, not blanket university-only wording. |
| AMD AI Developer Program / Developer Cloud | Official cloud page confirms complimentary $100 cloud credits for programme members. | Membership and actual redemption state unverified; this is not a cash grant. Current page also advertises paid use, which is not approved. |
