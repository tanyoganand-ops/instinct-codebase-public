# Open-source claymorphism UI on GitHub: top 5

Checked 4 Oct 2026. All links returned HTTP 200 via the GitHub API. Licences read from the API, or from package.json where GitHub did not detect one.

| # | Repo | Licence | Stars | Last push | Fit |

| 1 | https://github.com/codeAdrian/clay.css | MIT (package.json; no LICENSE file detected by GitHub) | 574 | Nov 2022 | Most popular. One micro class plus SASS mixin that adds clay shadows to any element. Drop-in, framework-free, but dormant. |

## Bonus reference
https://github.com/nexu-io/open-design/blob/main/plugins/_official/design-systems/claymorphism/DESIGN.md (repo Apache-2.0, 99k stars, link live). A claymorphism design-system spec file, handy as a prompt/brief for a builder rather than code.

## Caveats
- Stars are low outside clay.css. None of these is a polished, large component library; expect to restyle.
- Licences marked "package.json" are declared there only; no detected LICENSE file on GitHub for those repos (clay.css, TactileCSS had none detected by API; raw LICENSE fetch also failed).
- I did not run or visually test any of the code.
