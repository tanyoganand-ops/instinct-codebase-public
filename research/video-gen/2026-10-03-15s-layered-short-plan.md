# 15-second editorial Short: layered production plan

Date: 3 October 2026. Status: proposed storyboard and assembly contract, not a rendered video. Companion: `2026-10-03-insiderforce-format-research.md`.

## Concept: "Stop copying your notes"

One visual story: a messy note becomes three clear action cards. This is an original conceptual automation demo, not a claim that a named AI product performs it. All example names and tasks are fictional. Borrow the inspected references' editorial grammar, not their branding, scripts, music or exact layout.

Design decision: **34 separate visual nodes, six beats, one persistent canvas.** The note, its text, three output cards, each card's text, chips, connectors, cursor, captions and transitions are separately addressable. Do not export a whole scene as one PNG.

## Format and design tokens

- 1080 x 1920; 30fps; 450 frames, numbered 0-449. Final video length exactly 15.0s.
- Colour: paper `#F4F3EF`, ink `#171717`, muted `#686868`, accent `#D06D43`, pale card `#FFFFFF`.
- Typography: one licensed sans family, regular + bold; use locally installed, verified font files. No autogenerated words inside images. Suggested sizes: hero 108px; card title 48px; main caption 60px; chip 36px. Size is a starting point, then inspect at 360px-wide preview.
- Proposed conservative working area: x=96..900, y=210..1530. Keep essential text away from the right control rail and bottom metadata. This is a design margin, not an official invariant safe zone; test the actual Shorts overlay before publishing.
- Hero zone y=250..450. Demo zone y=540..1110. Caption zone y=1250..1420.
- Card corners 28px; shadow soft and quiet; no oversized glow. One accent colour per beat.
- The UI screenshot slot is optional, replaces only the inner demo content. Frame, mask, shadow and caption remain separate. This version uses original vector/UI content and needs no screenshots.

## Voiceover draft and captions

39 words, approximately 156 words/minute if spoken continuously for 15s. This is a target, not verified speech timing. Record first; retime caption boundaries from the recording before final export.

> Stop copying your notes. Turn the mess into actions. Extract each task, give it an owner, then set a deadline. Now you've got a plan you can actually use. Same notes. Clear next steps. That's the workflow to automate.

Do not read every tiny card label aloud. Captions live as text layers, not in the background image. Display only the current phrase, maximum two lines. The final voiceover sentence can be omitted if it crowds the payoff; preserve the 15s runtime rather than rushing speech.

The inventory totals 34 visual nodes. Repeated note lines, cards, chips and checkmarks each remain independent.

Audio is separate: optional voiceover WAV, quiet music bed with cleared licence, and three short original/cleared sound cues. Do not use sound as the only indicator of the action.

## Geometry and reusable components

All coordinates use the 1080x1920 master; each node specifies its own anchor.

- Demo frame: x=126, y=540, w=750, h=570. Keep shadows inside the working region.
- Opening note: x=166, y=620, w=280, h=340; rotation -4 degrees.
- Destination cards: x=516, y=600/762/924, w=304, h=138. Labels wrap once if needed, without shrinking below readable size.
- Output payoff: move the three cards to x=254, same y positions, w=500. Owner and deadline chips reposition within each card with the parent transform; their native labels stay editable.
- Separate inner clip from the outer frame transform. A replacement screenshot must not pull its frame, text or shadow into the image file.
- Reusable building blocks: `TextReveal`, `CardShell`, `ImageSlot`, `Chip`, `PathDraw`, `CursorMove`, `PaperWipe`. Parameters, not duplicated hand-edits, change topic/content/theme.

## Motion contract

- Standard text entry: 9-12 frames, y +24px to 0, opacity 0 to 1. Important words can reveal through a mask; never animate unreadable letter soup.
- Card entry: 12-18 frames, restrained ease-out, tilt toward 0 degrees, scale 0.96 to 1.00. No continuous bounce during reading.
- Chip entry: 8-10 frames, scale 0.94 to 1.00; use stagger instead of simultaneous bursts.
- Connector/check draw: normalize SVG path length and animate reveal progress independently.
- Secondary depth: shadow spread/opacity follows card elevation, not an unrelated floating shadow.
- Deterministic: every state derived from integer frame and seeded configuration. No `Date.now()`, network-loading text, uncontrolled randomness or wall-clock transitions during render.
- Use global frame for story windows and `localFrame = frame - start` inside an asset. Clamp outside-window transforms. Pin the renderer version before implementing; do not assume fetched documentation snippets are executable.

## Automation pipeline and quality gates

1. Content input: one accurate promise, source note, three fictional/approved tasks, short narration, optional owned image. Named real-tool demos require live capability verification first.
2. Build the full manifest from reusable components. Validate unique IDs, 34-node inventory, valid paths, bounded coordinates, known font licence, no unapproved claims and complete frame coverage.
3. Generate or record voice, then obtain real timings. Refit captions and cues. If voice is longer than 15s, shorten the script rather than time-stretching it into rushed speech.
4. Render a silent animatic first. Export at fixed frame rate; confirm 450 frames and 15s. Then add timed audio and export the review MP4.
5. Inspect actual pixels at frames 0,9,60,119,120,194,195,269,270,312,374,375,425,426,449 and at entrance midpoints. Watch the complete video at normal speed and on a 360px-wide preview. Verify layering, mask boundaries, caption readability, crop, shadow clipping and payoff hold. Fix and inspect again.
6. Inspect frame 449 -> 0 loop with audio. A visual match alone does not guarantee a natural spoken loop. If it jars, keep a clean ending instead.
7. User review before any publication. This task includes planning only; no uploads, channel posts or spending are authorised by it.

Acceptance criteria: understandable on mute, no blank opening, complete payoff by 12.5s, native editable text, independently inspectable nodes, no static-slide substitute for the extraction movement, no caption under the platform controls, and no duplicated source/output text artefact.

## Build order

1. Note-to-card movement + readable typography. This is the main quality test.
2. Owner/deadline chips and payoff hold.
3. Depth, connectors, cursor, restrained transitions.
4. Voice and sound last. Keep the render deterministic and reuse the template only after the first animatic passes review.
