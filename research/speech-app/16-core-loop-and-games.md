# Core loop, accessibility, game list (2 Oct 2026 spec)

PROPOSAL. Written by a task agent 2 Oct ~17:24, sent to P as little-steps-coreloop-spec.txt on WhatsApp at 17:25. Spec only, nothing built or published. All original, no Speech Blubs branding or assets.

## Core loop (about 90 sec per round, 5 rounds per session)
1. Greet: mascot, one soft sound, one-line prompt shown as text and spoken.
2. Try: one big target, 2-3 choices max, 3 seconds of calm before anything can fail.
3. Respond: no fail state, no red, no buzzer. Wrong pick: mascot tilts, item wiggles back, hint glows.
4. Adapt: 2 misses lowers difficulty (fewer choices, larger hint). 3 hits in a row raises one step.
5. Celebrate: small bloom animation and a garden sticker. No scores or timers shown to the child.
6. Rest: breathing screen (cloud expands and shrinks), clear "all done", no autoplay into more.

## Accessibility rules
- Touch targets at least 96px with generous spacing. Tap, tap-and-hold, drag all work. Optional dwell/hover select for motor impairment. Optional switch-scan (one switch cycles choices).
- Spoken prompt plus text plus icon on everything. Dyslexia-friendly font option. AA contrast or better (dark sage on cream).
- Reduced-motion toggle and sound-level toggle. No flashing, no sudden loud sounds, no surprise full-screen animations.
- Parent area gated by hold-to-open or simple sum: level, session length, quiet mode. Progress saved on-device.

## 12 games, grouped by skill
Speech and sound
1. Sound Friends: copy mouth shape and sound of an animal friend (camera mirror optional).
2. Syllable Steps: hop stepping stones, one per syllable.
3. Echo Pond: mascot says a word, ripples show rhythm, child taps it back.
4. Build My Message: pick 2-3 picture cards to make a request ("I want + juice").
Language
5. Name It Garden: tap the matching object, watch it grow.
6. What Comes Next?: 2-4 step daily routine sequence.
7. Opposites Bridge: drag matching halves (big/small).
Memory and attention
8. Gentle Pairs: 2x2 growing to 3x4, no timer.
9. Lantern Follow: track a slow firefly with finger or eyes.
10. Spot the Change: two scenes, find what changed.
Thinking and motor
11. Sort Together: sort by colour, shape, size into baskets.
12. Paint the Wind: slow free drawing with big strokes, for motor control and calm.
Possible later: feelings faces, two-player turn-taking game with a parent.

Six of these already exist in the prototype (Sound Friends, Syllable Steps, Build My Message, What Comes Next?, Gentle Pairs, Sort Together). New: Echo Pond, Name It Garden, Opposites Bridge, Lantern Follow, Spot the Change, Paint the Wind.

## Visual direction (follows P's stated design preferences)
- Painted pastoral palette (cream, sage, sky, peach), soft curves, not literal Ghibli scenery or characters.
- Frosted-glass cards over textured painted backgrounds with Gaussian-blur layers.
- Slow continuous ambient motion (drifting clouds, swaying grass).
- Custom mascot and icons, no emojis.
- Parallax valley world map where each game is a place.
