## Format and classification

- One file per top-level question, base name `8035-3-YYYY-Q0N`; current repository index uses upload-prefixed filenames such as `questions/1-8035-3-2018-Q01.pdf`. Follow actual index paths, not guessed filenames.
- Original question pages retained, including answer lines; header band gives theme, marks and command words. Mark schemes clipped per question. This geography layout differs from the physics pack that removes answer lines.
- Section A: paper theme (water, rainforest, energy, waste, tourism, housing) plus skill (data/map/explanation/extended answer/decision).
- Section B: B1 enquiry design/sampling/risk, B2 methods, B3 presentation, B4 analysis/conclusions, B5 evaluation; human/physical and secondary tags for mixed questions.
- Relevant pre-release figure pages appended to every Section A question file. OS key inserts included for 2018/2022/2024 Q2.
